# DLSS5 NR 逐步使用流程

[返回项目说明](../README.zh-CN.md)

> 原版运行库下载源已接入并实际下载验证，本项目Release只提供MIT桥接组件。
> 自动原版无需自行寻找下载地址；需要自定义／社区版时，使用手动模式保留自己的文件。

整个过程是：**安装插件 → 重启界面 → 等待自动准备 → 选择显卡 → 开启DLSS5 NR → 正常生成图片。**

## 1. 安装前确认

先打开你平时使用的Forge，确认它能正常生成图片。
本插件目前针对 **64位Windows上的Forge-neo，Python 3.12或3.13**；Python版本可以在Forge启动日志中看到。
需要兼容的NVIDIA显卡，目前实测的是RTX5060Ti，其它组合尚不保证兼容。

这一步只是确认能否使用，不需要重装Forge或更换原来的出图模型。

## 2. 安装插件

打开 **Extensions（扩展）→ Install from URL（从网址安装）**，
填写以下插件仓库地址，其余输入框保持默认，点击 **Install（安装）**。

```text
https://github.com/silvermoong/sd-webui-forge-dlss5-nr.git
```

此时Forge会下载插件，并安装插件自己的依赖。等它结束，不要反复点击安装。
插件不会替换Forge的PyTorch环境，也不要求你手动运行Python命令。

## 3. 重启Forge界面

切换到扩展页面的 **Installed（已安装）**，点击
**Apply and restart UI（应用并重启界面）**，等待界面重新打开。

要等当前出图任务结束后再做这一步。浏览器按F5不是这里说的重启，也不用重启电脑。
看到“Installed”只能证明插件代码已放进去，接下来还要检查准备状态。

## 4. 等待首次准备

回到 **txt2img（文生图）** 或 **img2img（图生图）**，展开该页的 **DLSS5 NR**。
**首次准备** 位于三页参数面板下方，预设栏仍在参数上方；独立增强页也使用这个顺序。
默认选择 **自动下载原版**；缺少时从已记录的[第三方发布源](../MODEL_SETUP.zh-CN.md)下载，准备区会显示进度或下一步提示。
已有有效文件会直接复用，不会每次打开都重新下载。

运行库自动保存到 **Forge模型目录下的`DLSS-NR`文件夹**，默认是`models/DLSS-NR`。
Forge配置了其它模型目录时也会跟随。你不需要找DLL、复制文件路径或选择保存位置。

如果出现错误，先按后面的“遇到问题”处理，不要急着重装整个Forge。

### 需要手动／社区运行库时

在“运行库来源”选择 **手动自定义／社区版**。选择后不再自动下载，刷新和重启也会保留选择。
展开 **高级：诊断与修复**，选择自己的`nvngx_dlssnr.dll`，点 **导入运行库副本**。
也可以自己放入“当前运行库目录”，默认是`models/DLSS-NR/manual`，再点首次准备区的重试按钮。

这里给40系等需要社区兼容文件的用户留出选择空间，不代表本项目已实测该文件或显卡。
手动模式只检查DLL格式和复制完整性，不验证NVIDIA签名；请只使用可信来源。
自动原版和手动文件分开保存，切换前等待当前NR任务结束，不会自动替换已有不同文件。

## 5. 选择显卡

点击 **列出显卡**，在下拉框里按型号选择要用的NVIDIA显卡。
如果刚点过 **重试运行库并检测显卡**，列表已经更新，直接选择即可。

等就绪状态显示 **“已准备好，可以使用……生成。”** 后继续。
只列出显卡不会运行NR模型；插件也不会替你偷偷改选另一张卡。

## 6. 先生成一张测试图

使用你已经能正常出图的模型和提示词，先设为：

- 图片尺寸：**512×512**。
- 批量大小：**1**；批次数：**1**。
- 暂时关闭 **Hires. fix（高清修复）** 和 **ADetailer**。
- DLSS5 NR只启用 **1st第一页**，其余两页关闭，参数先保持默认。

勾选 **DLSS5 NR标题栏的开关**，然后点击Forge原来的 **Generate（生成）** 按钮。
没有另一个专门的NR生成按钮；这一轮会先正常出图，再执行NR增强。

确认正常得到图片，并在图片生成参数中看到`DLSS5 NR`记录、`status`为`done`。
需要读取已保存PNG的参数时，可使用Forge的 **PNG Info（PNG信息）** 页面。
“文件已准备好”不代表模型已经执行成功；最终仍要看这次的成图与结果记录。

## 7. 后续正常使用

首次测试成功后，再根据需要恢复高清修复、ADetailer或调整参数。
不需要每次重新安装插件、下载运行库或修复依赖。

面板有 **1st / 2nd / 3rd三页**，各页开关、NR参数和插入时机互相独立。需要第二或第三遍时，进入对应页并勾选“启用此页”。
切页只是查看和编辑该页，不会运行模型；关掉一页会跳过它，数值仍保留。三页全关时不会执行NR。

在文生图中，不开高清修复时，所有启用页在首轮生成后按页序处理。开启高清时，先执行所有高清前的启用页，再高清修复，
最后执行所有高清后的启用页；各阶段内按页序，均在脸部修复之前。
例如第2页前置、第1/3页后置，实际是：**首轮 → 第2页 → 高清修复 → 第1页 → 第3页 → ADetailer**。

“复制上一页参数”复制参数和时机，不替你勾选本页开关。每页可以同参或异参；“本页混合”相对本页收到的图像计算，
混合结果再送入下一页，不是每页都从最初原图重新开始。更多遍数会增加处理开销，也可能累计改变原图，建议逐遍比较。

设置上方有常驻预设栏。下拉框可选择已有预设，也可直接输入新名字；右侧四个方形按钮从左到右是 **载入、保存/覆盖、删除、刷新列表**，悬停可查看名称。
选择后点载入才会应用参数；输入新名字后直接点保存即可新建，同名则覆盖。删除只移除预设，当前参数保留；在其它页面保存后可点刷新更新列表。
命名预设仍保存整组三页的参数、页开关与插入位置，不改总开关或显卡。
载入旧单页预设时，第一页恢复原参数，第二、三页恢复为关闭的默认值。XYZ预设轴同样使用整组快照，不在格子之间串参。
不需要增强时，取消DLSS5 NR标题栏的勾选，即可继续按原来的流程出图。

### 不采样，直接增强一张图片

打开最上层的 **DLSS5 NR** 标签，它与文生图、图生图并列。上传图片，在右侧确认显卡与运行库就绪，
启用需要的参数页，然后点击 **增强图片**。默认只启用第一页，不需要开启总开关或设置提示词。

这里直接处理上传像素，不调用图生图、VAE、扩散模型或ADetailer，也不缩放图片；EXIF方向和颜色配置会规范化，透明度保留。
输入图片区同时承担上传和原图预览，不另放一块原图框；上传后保留紧凑文件条，清除后可重新上传，旧结果与回执也会清空。
旁边结果区的下载按钮输出带执行回执的PNG。输出使用临时缓存，需要的结果请通过下载按钮保存。
普通8位静图可用，动画、视频、HDR和批量上传不支持；长边不能超过8192像素，面积不能超过32 x 1024 x 1024像素。

**取消**只取消这个浏览器会话的独立NR任务，不点击Forge的全局停止。状态未知时等后台确认，不反复提交。
错误或新一轮开始时会清掉旧结果，不把旧图当新结果；三页全关闭时不能开始增强。
此页与文生图、图生图共用预设和运行库，但参数互相独立。更新安装副本后，仍需等任务结束再重启Forge才会出现新标签。

### 在图生图页使用

进入 **img2img（图生图）**，正常放入输入图，设置尺寸、重绘幅度以及需要的蒙版，再展开该页的 **DLSS5 NR**。
先只启用第一页并确认该页显卡快照就绪；勾选总开关后，仍使用Forge原来的生成按钮。

执行顺序是 **原生图生图采样及latent回调 -> 启用的NR页（1、2、3） -> 原有修脸/ADetailer与蒙版回贴**。
不修改上传原图或重绘幅度；设为0也不等于关闭NR。局部重绘仍由Forge处理裁剪和蒙版，开启回贴时沿用原生未蒙版内容恢复。
ADetailer等一轮生成中的嵌套重绘不会再次执行NR。

图生图的三页固定在“图生图后”，不跟随文生图的高清开关。载入含高清前后设置的预设只调整当前页控件，不改预设文件。
文生图与图生图的总开关、参数和环境快照相互独立，预设和后台共用；切换共用运行库来源后，刷新界面再使用另一页。
图生图已做CPU、浏览器及RTX5060Ti上的512x512功能验收；分块放大与其它独立生成任务的特殊脚本尚未验证。

## 遇到问题

| 看到什么 | 应该怎么操作 |
| --- | --- |
| 下载中断、网络连接失败 | 检查网络，再点首次准备区的 **重试运行库并检测显卡**。它不会重装Python依赖。 |
| 缺少依赖、依赖已损坏 | 展开 **高级：诊断与修复**，点击 **修复依赖并继续**。 |
| 依赖修复未完成 | 检查网络，在同一个位置再次点 **修复依赖并继续**。原始错误可在 **诊断信息** 中查看。 |
| NR正在工作，或无法确认后台空闲 | 先等任务结束。持续无法查询时，在其它任务也结束后重启Forge再试，不强行修复。 |
| 更新后仍无分页，或提示后台未加载多页支持 | 等任务空闲后重启Forge，再刷新页面；仅按F5不会重新加载Python代码。 |
| 更新后图生图页仍无NR面板 | 确认安装副本已经更新，并等任务空闲后重启Forge；工作仓库修改不会自动部署到安装副本。 |
| 顶层没有独立DLSS5 NR标签 | 确认安装副本包含独立增强页更新；等任务空闲后重启Forge，单纯刷新不会重新加载插件代码。 |
| 下载文件不可用 | 这是项目发布或下载来源的问题，不是你的电脑问题；等待维护者处理，无需重装Forge。 |
| 手动模式缺少运行库 | 导入自己的DLL，或放到当前目录后重试；手动模式不会自动下载原版。 |
| 生成时报显卡、驱动或运行库不兼容 | 先关闭DLSS5 NR恢复普通出图，记录本次错误再排查；不要修改驱动安全策略或删除整个模型目录。 |

**下载重试和依赖修复是两件事。** 首次准备区的重试按钮负责运行库准备；只有高级选项里的显式修复才会安装依赖。
依赖修复只关闭本插件已确认空闲的后台，不会打断正在执行的NR任务，也不卸载其它应用的模型。

切回 **自动下载原版** 时，手动文件会留在独立目录。导入不会移动或删除用户提供的源文件。
